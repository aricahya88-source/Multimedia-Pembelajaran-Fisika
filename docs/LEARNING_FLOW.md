# Learning Flow MPF — 2 SKS

MPF dirancang untuk **16 pertemuan**, masing-masing **2 × 50 menit tatap muka**. LMS hanya menyediakan **1 unit materi inti per pertemuan**. Bukti proses tiap pertemuan melekat pada dua proyek utama dan bukan tugas terpisah.

## Fase 1 — Foundations of Multimedia Learning (Pertemuan 1–2)
Ruang lingkup multimedia → Cognitive Load Theory → prinsip multimedia.

## Fase 2 — Project 1: Multimedia Design (Pertemuan 3–8)
Needs analysis → flowchart/storyboard → aset teks/visual/audio → audiovisual/animasi/simulasi → interaction design → UTS design review.

## Fase 3 — Project 2: Interactive Implementation (Pertemuan 9–13)
Implementasi struktur/aset → interaktivitas digital → sensor/microcontroller sebagai interaktivitas → data/web/PWA → integrasi beta product.

## Fase 4 — Testing, Revision & Showcase (Pertemuan 14–16)
Functional/content/usability testing → evidence-based revision → final QA → demo/oral defense/refleksi.

## Kerangka microcontroller
`Learner/Phenomenon → Sensor/Input → ESP32/Arduino → Data/Process → Multimedia/Actuator → Feedback → Learner Response`.

Microcontroller bukan tujuan mata kuliah. Ia hanya dipilih jika memperkaya interaktivitas dan membantu tercapainya tujuan pembelajaran fisika.
